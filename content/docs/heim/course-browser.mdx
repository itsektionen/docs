The Course Browser is a tool that allows you to browse the courses offered by KTH.
It works using KTH's API, [KOPPS](https://api.kth.se/api/kopps/v2/).

Unfortunately, KOPPS is discontinued or something (not super clear at the moment).
Right now, we are considering just scraping all the data and providing the service ourselves.
