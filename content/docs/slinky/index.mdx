Slinky, the <ins>S</ins>imple <ins>Link</ins> shorterner (<ins>y</ins>oooooo wassup???),
is a lightweight and easy-to-use link shortening service that allows you to create
shorter, more manageable URLs for your links.

The backend is built with [Golang](https://go.dev/), and the frontend is built with [React](https://reactjs.org/).
