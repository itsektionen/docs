Welcome to the IT Chapter's system documentation!

Here, you can find documentation for the various systems built for and by the IT Chapter, and other information about the chapter.
The purpose is to provide a comprehensive overview of the IT Chapter's systems and
their respective functionalities. It also reduces the dependency on old students, ensuring the longevity of
the systems and reducing duplicate work.

The docs are open to the entire chapter to contribute.

If you are unsure about anything, do not hesitate to reach out to the person listed in the footer or [init](https://init.kth.it) / [SMN](mailto:sture@kth.it)
and we will either help you or find the person who knows how to help you.

## Is something missing?

Not everything is documented, so if something is missing, feel free to ask the person responsible for the information to add it to the docs.

If you are unsure of who to contact, some documentation has contact information in the footer.
If it is missing from the footer or it lacks a page entirely, feel free to ask someone from [init](https://init.kth.it) if it is software related
or [SMN](mailto:sture@kth.it) if it is hardware related. (don't worry if you get it wrong, we will help find the correct person)

If you have information that is not present in the docs, do not hesitate to [write some documentation for it](./writing-documentation/index.mdx)
